# CCNA-Enterprise-Multi-Site
## 📌 Description

Enterprise multi-site network project using Cisco Packet Tracer.

## 🎯 Objectives

- VLAN configuration
- Inter-VLAN Routing
- WAN connectivity
- OSPF dynamic routing
- Network verification and troubleshooting

## 🏢 Network Architecture

The network consists of two sites:

- Site A
- Site B

## 🛠️ Technologies

- Cisco Packet Tracer
- VLAN
- 802.1Q Trunk
- Router-on-a-Stick
- OSPF
- IPv4

## 📂 Project Structure

- `general/` — Network documentation
- `configuration/` — Cisco device configurations

## ✅ Final Goal

Enable communication between the different VLANs and between Site A and Site B using OSPF.
