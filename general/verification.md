# Verification

## VLAN Verification

show vlan brief

## Trunk Verification

show interfaces trunk

## OSPF Neighbor Verification

show ip ospf neighbor

## Routing Table Verification

show ip route

## Connectivity Tests

Ping between hosts from different VLANs and different sites.

## Expected Result

- VLANs are operational.
- Trunk links are operational.
- Inter-VLAN routing is operational.
- OSPF adjacency is established.
- Routes are learned between Site A and Site B.
- End-to-end connectivity is successful.
